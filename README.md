# Jingfei He

I’m a Ph.D. student at Beijing Institute of Technology. My research focuses on generative models for remote sensing, especially how to use optical priors, control color, and preserve spatial consistency in SAR-to-optical image translation.

[Google Scholar](https://scholar.google.com/citations?user=tmThcsMAAAAJ)

## Selected Research

- **[DOGAN](https://github.com/Saturn-He/DOGAN)** (IEEE TGRS, 2025) uses optical priors from a pretrained DINO model to guide SAR-to-optical translation.
- **[ColorS2O](https://github.com/Saturn-He/ColorS2O)** uses sparse optical color anchors to control the colors of translated images.
- **[XTile-S2O](https://github.com/Saturn-He/XTile-S2O)** improves consistency across tile boundaries when translating full SAR scenes.
