# Jingfei He

I’m a Ph.D. student at Beijing Institute of Technology. My research focuses on generative models for remote sensing, especially how to use optical priors, control color, and preserve spatial consistency in SAR-to-optical image translation.

[Google Scholar](https://scholar.google.com/citations?user=tmThcsMAAAAJ)

## Selected Research

- **DOGAN** (IEEE TGRS, 2025) uses optical priors from a pretrained DINO model to guide SAR-to-optical translation. [Paper](https://doi.org/10.1109/TGRS.2025.3606979) · [Code](https://github.com/Saturn-He/DOGAN)
- **ColorS2O** uses sparse optical color anchors to control the colors of translated images. [Code](https://github.com/Saturn-He/ColorS2O)
- **XTile-S2O** improves consistency across tile boundaries when translating full SAR scenes. [Code](https://github.com/Saturn-He/XTile-S2O)
- **SWDiff** (IEEE TGRS, 2024) introduces a stage-wise diffusion model for hyperspectral image classification. [Paper](https://doi.org/10.1109/TGRS.2024.3485483)
- **SADBM** uses an edge-enhanced SAR image as the starting point of a diffusion bridge to preserve scene structure in SAR-to-optical image translation. [Project](https://github.com/AproZC/SADBM)
