# Jingfei He

I’m a Ph.D. student at Beijing Institute of Technology. My research focuses on generative models for remote sensing, especially how to use optical priors, control color, and preserve spatial consistency in SAR-to-optical image translation.

[Google Scholar](https://scholar.google.com/citations?user=tmThcsMAAAAJ&hl=en&oi=ao)


## Selected Research

- **DOGAN** (IEEE TGRS, 2025) uses optical priors from a pretrained DINO model to guide GAN-based SAR-to-optical image translation. [Paper](https://doi.org/10.1109/TGRS.2025.3606979) · [Code](https://github.com/Saturn-He/DOGAN)
- **ColorS2O** (under review) uses sparse colour anchors from an optical observation to control the colours of translated images. [Code](https://github.com/Saturn-He/ColorS2O)
- **XTile-S2O** (under review) shares context across neighbouring tiles to improve spatial consistency in full-scene SAR-to-optical translation. [Code](https://github.com/Saturn-He/XTile-S2O)
- **SADBM** uses an edge-enhanced SAR image as the starting point of a diffusion bridge to preserve scene structure in SAR-to-optical image translation. [Code](https://github.com/AproZC/SADBM)
- **SWDiff** (IEEE TGRS, 2024) introduces a stage-wise diffusion model for hyperspectral image classification. [Paper](https://doi.org/10.1109/TGRS.2024.3485483)
